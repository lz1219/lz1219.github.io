Linux 常用命令总结

无论是后端开发、运维部署还是排查线上问题，Linux 命令行都是绕不开的基本功。本文按使用场景梳理日常工作中最常用的命令，每条都附常用参数和示例，可以作为速查手册收藏。

一、文件与目录操作

这是使用频率最高的一组命令。

命令 作用 常用示例
pwd 显示当前所在目录 pwd
ls 列出目录内容 ls -lha（详细 + 隐藏文件 + 人类可读大小）
cd 切换目录 cd -（返回上次目录）、cd ~（回家目录）
mkdir 创建目录 mkdir -p a/b/c（递归创建多级目录）
touch 创建空文件 / 更新时间戳 touch app.log
cp 复制 cp -r src/ dest/（递归复制目录）
mv 移动 / 重命名 mv old.txt new.txt
rm 删除 rm -rf dir/（强制递归删除，慎用！）
ln 创建链接 ln -s /path/to/target link_name（软链接）

二、文件查看

命令 作用 常用示例
cat 查看整个文件 cat -n file.txt（带行号）
less 分页查看（可上下翻页搜索） less app.log，按 / 搜索，q 退出
head 查看开头 head -n 20 file.txt
tail 查看结尾 tail -f app.log（实时跟踪日志，排查问题必备）
wc 统计行数/字数 wc -l file.txt

三、查找文件与命令

四、文本处理三剑客：grep / sed / awk

grep：过滤搜索

sed：流编辑

awk：按列处理

其他高频文本命令：

命令 作用 示例
sort 排序 sort -nr -k2 file（按第 2 列数值倒序）
uniq 去重（需先排序） `sort file
cut 按分隔符取列 cut -d: -f1 /etc/passwd
diff 对比文件差异 diff -u old.conf new.conf

五、权限管理

Linux 权限用 rwx（读 4、写 2、执行 1）表示，分属主、属组、其他人三段。

常用权限值：644（普通文件）、755（可执行文件/目录）、600（私钥等敏感文件）。

十、网络相关

十一、压缩与解压

记忆口诀：c 创建、x 解压、v 显示过程、f 指定文件、z gzip。

十二、软件包管理

十三、管道与重定向

这是 Linux 哲学的核心：小工具组合完成复杂任务。

十四、实用快捷键

快捷键 作用
Ctrl + C 终止当前命令
Ctrl + Z 挂起当前任务（配合 bg/fg）
Ctrl + R 反向搜索历史命令（效率神器）
Ctrl + A / E 光标跳到行首 / 行尾
Ctrl + U / K 删除光标前 / 后的内容
Ctrl + L 清屏（等同 clear）
Tab 自动补全（连按两次列出候选）

总结

以上命令覆盖了日常 90% 的使用场景。建议的学习路径：

  1. 先熟练使用文件操作和 tail -f、grep 这套日志排查组合拳
  2. 再掌握 find、awk、sed 处理批量任务
  3. 最后通过网络和进程命令具备独立排查线上问题的能力

命令不用死记硬背，多用、多查 man 手册（如 man grep），自然而然就记住了。
